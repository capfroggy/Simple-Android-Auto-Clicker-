# Contributing

Thanks for helping improve Simple Android Auto Clicker.

## Project philosophy

Please keep contributions aligned with these principles:

1. **Simple** — avoid feature bloat.
2. **Local** — no cloud dependency for core functionality.
3. **Private** — no ads, analytics, tracking, or unnecessary permissions.
4. **Transparent** — permissions and behavior should be easy to understand.
5. **Free and open source** — core features should not be paywalled.

## Good contributions

Examples:

- Android compatibility fixes;
- accessibility improvements;
- clearer onboarding;
- bug fixes;
- performance improvements;
- translations;
- small optional controls that do not complicate basic use.

## Before opening a pull request

- Build the project successfully.
- Explain what changed and why.
- Avoid adding network permissions or tracking dependencies.
- Keep the user experience understandable without documentation.

## Feature requests

Open an issue describing the user problem first. Solutions should remain consistent with the project's minimal design.
