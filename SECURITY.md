# Security Policy

## Reporting a vulnerability

Please report security issues privately when possible rather than publishing exploit details in a public issue.

For ordinary bugs that do not expose user data or device security, use GitHub Issues.

## Security principles

Simple Android Auto Clicker intentionally keeps its attack surface small:

- no Internet permission;
- no remote API;
- no authentication system;
- no advertising SDKs;
- no analytics SDKs;
- no background cloud service;
- minimal third-party dependencies.

## Accessibility

Accessibility is a powerful Android capability. This project uses it only for the documented auto-clicking features.

Changes that expand Accessibility usage should be reviewed carefully and documented in the README and privacy policy.
